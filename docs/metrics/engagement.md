# Engagement Rate

## Definition
Engagement rate measures how actively users interact with a product, 
feature, or content within a defined time period.

It indicates whether users find value in what they are using — 
not just that they opened it, but that they did something meaningful with it.

## How It Is Calculated

$$
\text{Engagement Rate} = \frac{\text{Active Interactions}}
{\text{Total Sessions}} \times 100
$$

**Active interactions include:**

- Clicks on core features
- Time spent above a minimum threshold
- Actions completed (searches, exports, shares)

## Who Uses This Metric

| Team | Purpose |
|---|---|
| Product | Evaluate feature adoption |
| Data | Build usage models |
| Marketing | Measure campaign effectiveness |
